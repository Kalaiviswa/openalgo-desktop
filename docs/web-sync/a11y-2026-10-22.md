# Accessibility fixes to carry to OpenAlgo web (2026-10-22)

The accessibility scan (`e2e/accessibility.spec.ts`) now covers the Health
Monitor (`/health`) in light and dark, with every read failing and with
checks in warning and failure, alerts and an unconfirmed order. In the light
theme axe found text below 4.5:1 that the desktop carried over from OpenAlgo
web; the same code is in the web today. As decided on 2026-10-20, it is fixed
here and noted for the web. Each edit is a class change; the dark theme keeps
the web's colours, which pass.

Web line numbers are from the web checkout at `2b52f466`; search for the old
text if they have moved.

## `frontend/src/pages/HealthMonitor.tsx`

| Web line | Old | New | axe rule |
| --- | --- | --- | --- |
| 82 | `pass: 'text-green-500',` (a metric card's value) | `pass: 'text-green-700 dark:text-green-500',` | color-contrast |
| 83 | `warn: 'text-yellow-500',` | `warn: 'text-yellow-800 dark:text-yellow-500',` | color-contrast |
| 472 | `<p className="text-sm text-muted-foreground">` ("Last updated (IST)" in the status banner) | `<p className="text-sm text-neutral-600 dark:text-muted-foreground">` | color-contrast |
| 820 | `<p className="text-sm text-muted-foreground">{alert.message}</p>` | `<p className="text-sm text-neutral-600 dark:text-muted-foreground">` | color-contrast |

The values are 24 px bold, so 3:1 is enough: green-500 and yellow-500 measure
about 2.3:1 and 1.9:1 on the white card (red-500, 3.8:1, passes and stays).
The banner and alert texts sit on the status tints (`bg-red-500/10`,
`bg-yellow-500/10`), where the muted grey falls below 4.5:1.

## Desktop only (nothing to carry)

The desktop's own Health parts use the same pair on the same tints: the
unconfirmed order rows (`src/components/desktop/health/UnconfirmedOrders.tsx`)
and the "could not refresh" lines (`NotRefreshed.tsx`), which also appear in
the status banner.
