# Accessibility fixes to carry to OpenAlgo web (2026-10-20)

OpenAlgo Desktop's signed-in pages now pass axe (WCAG 2 A and AA, serious
and critical) with no exceptions (`e2e/accessibility.spec.ts`, KNOWN empty),
in light and dark. Every finding below was in the page as carried over from
OpenAlgo web, and the same code is in the web today. The maintainer chose to
fix them here and note them for the web (2026-10-20). Each edit is a class
or attribute change, so it can be applied to the web by hand.

Web line numbers are from the web checkout of 2026-10-20; search for the old
text if they have moved.

## `frontend/src/index.css` (sonner's rich colours)

`frontend/src/app/providers.tsx` turns on `richColors` for the toaster.
Sonner's own light-theme text shades are below 4.5:1 on its toast
backgrounds: error 4.36, info 4.35, success 4.29 and warning 3.07:1. Add,
at the end of `index.css`:

```css
html [data-sonner-toaster][data-sonner-theme='light'] {
  --success-text: hsl(140, 100%, 24%);
  --info-text: hsl(210, 92%, 40%);
  --warning-text: hsl(31, 92%, 32%);
  --error-text: hsl(360, 100%, 40%);
}
```

This is 5.2 to 5.5:1, the same hues. Its selector has one more element than
sonner's, so it wins whatever order the styles load in. The dark theme keeps
sonner's values, which are above 6:1. axe rule: color-contrast.
